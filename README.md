# Clerk Studio

這是一個適合手機使用的國考複習、Clerk 2 輪訓待辦與 CSV 資料分析網站。

- `index.html`：網站主程式。
- `dashboard.js`：今日任務與國考課程進度整合（v1.2）。
- 私人輪訓資料與個人學習進度**不會存放在公開程式庫**。

## 初次使用

1. 使用 Safari 開啟 https://mark082912.github.io/clerk-studio/ 。
2. 點首頁「匯入我的資料」或上方「備份」。
3. 選擇「合併個人學習／輪訓資料」，匯入 ChatGPT 提供的私人 JSON 資料包。
4. 回首頁查看當日待辦、國考下一單元、每週 checkpoint。完成打勾會儲存於目前瀏覽器。
5. 定期用「下載完整備份」備份。換裝置不會自動同步。

## 隱私

本站是靜態網站，無伺服器帳號、雲端資料同步與背景推播。請勿將個人匯入包、可識別病人的姓名、病歷號等放進 GitHub Repository。題庫為原創示範題而非正式國考歷屆題，臨床知識請核對最新指引。
