## 📱 手機安裝與離線使用

使用 iPhone Safari 開啟網站 → 分享 →「加入主畫面」。本站透過 `manifest.webmanifest`、`sw.js` 與 `app-icon.svg` 提供可安裝的網頁應用程式（PWA）。

首次連網開啟且離線資源快取成功後，離線也可練習已載入的題庫、瀏覽既有任務與部分分析；首次使用、程式更新、官方 PDF 原卷連結仍需網路。請勿在需要保存資料時使用私密瀏覽或清除 Safari 網站資料。

**離線不代表個人資料已同步或備份**：localStorage 仍在目前裝置及目前 Safari 網站資料容器內，其他裝置、Safari 與主畫面網站若採不同儲存容器也可能互不共享。務必下載完整備份。

## 隱私及限制
本站為公開的 GitHub Pages **靜態網站**，公開 Repository 內沒有使用者的病人資訊、私人輪訓 JSON、答題歷史。所有個人學習記錄存在瀏覽器 localStorage；模擬考進行中的資料存在 sessionStorage。沒有雲端跨裝置同步、伺服器通知、登入系統，Safari 關閉私密瀏覽／清除網站資料後可能消失。請定期使用「備份 → 下載完整備份」，勿將私人資料包提交到公開 GitHub。

考點練習解釋屬教學用途，非正式醫療建議，隨臨床指引／疫苗政策更新可能需要修訂。資料有異議時以官方最新公告與高品質臨床指引核對。
