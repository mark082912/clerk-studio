## 🩺 臨床助手（Clerk 2）

首頁右側／手機底部「**臨床**」工作區包含 6 個模組：
1. **📝 病歷格式**：每日 SOAP / Progress、Clerk Admission、Weekly Summary、全人照護病歷、Off-duty / Handoff、Discharge、Acceptance / Transfer。每一欄可獨立複製，未填資料顯示「待核實」。一般住院病歷英文；全人照護中文；精神科紀錄使用中文。SOAP 必包含疼痛評估、治療反應與是否加用止痛藥的核對欄位。
2. **📚 國考導向教學**：Level 1 一階基礎→ Level 2 二階鑑別→ Level 3 臨床處置，再延伸 OSCE / EPA 操作步驟與老師可能追問。
3. **🎙 報告草稿**：中文優先的一分鐘摘要（可直接複製口述段落）、Case Report、Review、EBM / PICO 架構。
4. **🩺 查房 Q/A**：優先抓 5–10 項本科技能與常考問題。若有當日 patient list，先去識別後產生可交給 ChatGPT 處理的精確提示詞。靜態站不會自行推論病人檢驗、產生全新 AI 問答。
5. **☎️ 值班 SBAR**：整理電話交班、最新 vital signs、評估及上級協助請求，附安全升級和 read-back 核對。
6. **✅ 科部繳交清單**：PED 小兒科 2026-10-26 至 11-08 部分已核實規則與日期；其餘科別只顯示待確認架構，不臆造正式期限，可建立去重待辦。

**安全設計**：臨床輸入欄位只在目前分頁的記憶體中暫存，不自動存入 localStorage、GitHub 或伺服器。重整即清除，請自行複製草稿。勿輸入病人姓名、病歷號、生日等識別資訊。這是**結構化格式與提示詞工具，不是內建 AI 自動讀病歷**；正式提交前使用者與臨床教師需核對內容、文句及醫囑。

## 📱 手機安裝與離線使用

使用 iPhone Safari 開啟網站 → 分享 →「加入主畫面」。本站透過 `manifest.webmanifest`、`sw.js` 與 `app-icon.svg` 提供可安裝的網頁應用程式（PWA）。

首次連網開啟且離線資源快取成功後，離線也可練習已載入的題庫、瀏覽既有任務與部分分析；首次使用、程式更新、官方 PDF 原卷連結仍需網路。請勿在需要保存資料時使用私密瀏覽或清除 Safari 網站資料。

**離線不代表個人資料已同步或備份**：localStorage 仍在目前裝置及目前 Safari 網站資料容器內，其他裝置、Safari 與主畫面網站若採不同儲存容器也可能互不共享。務必下載完整備份。

## 隱私及限制
本站為公開的 GitHub Pages **靜態網站**，公開 Repository 內沒有使用者的病人資訊、私人輪訓 JSON、答題歷史。所有個人學習記錄存在瀏覽器 localStorage；模擬考進行中的資料存在 sessionStorage。沒有雲端跨裝置同步、伺服器通知、登入系統，Safari 關閉私密瀏覽／清除網站資料後可能消失。請定期使用「備份 → 下載完整備份」，勿將私人資料包提交到公開 GitHub。

考點練習解釋屬教學用途，非正式醫療建議，隨臨床指引／疫苗政策更新可能需要修訂。資料有異議時以官方最新公告與高品質臨床指引核對。
